# Modelo Operativo · Conceptos Clave

## 1. Componentes del modelo operativo (OperatingModel Canvas)
1. **Procesos** — value streams, end-to-end
2. **Organización** — estructura, roles, RACI
3. **Capacidades** — gente, tools, conocimiento
4. **Información y métricas** — KPIs, dashboards, reporting
5. **Suppliers** — partners, contratos, governance
6. **Locations** — geografía, sites, hubs
7. **Sistemas** — ERP, CRM, plataformas

## 2. Arquetipos de modelo operativo
- **Centralizado** — economías de escala, control
- **Descentralizado** — agilidad local, cercanía cliente
- **Federado** — combina ambos según función
- **Shared Services** — back office centralizado

## 3. Frameworks
- **APQC Process Classification Framework** — 12 categorías de procesos
- **Hammer Process Maturity** (PEMM) — 5 niveles
- **CMMI for Services** — capacidad organizacional

## 4. Métricas clave
- Productividad por FTE
- Costo por transacción / por unidad
- Tiempo de ciclo (cycle time)
- First-time-right rate
- SLA cumplimiento
- Customer effort score

## 5. Procesos típicos a optimizar
- Atención de consultas / Customer service (caso BEI)
- Gestión de demanda y proyectos
- Procurement / P2P
- Cierre contable
- Onboarding empleados / clientes
- Gestión de incidencias / tickets
