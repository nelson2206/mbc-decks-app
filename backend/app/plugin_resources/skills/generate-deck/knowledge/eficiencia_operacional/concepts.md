# Eficiencia Operacional · Conceptos Clave

## 1. Metodologías
- **Lean** — eliminar desperdicios (8 muda)
- **Six Sigma** — reducción variabilidad (DMAIC)
- **TOC** (Theory of Constraints) — cuello de botella
- **BPM** (Business Process Management)
- **Hyperautomation** (Gartner) — RPA + IA + low-code

## 2. Las 8 muda (Lean)
Defectos · Sobreproducción · Esperas · Talento desperdiciado · Transporte · Inventario · Movimiento · Sobre-procesamiento

## 3. Palancas de eficiencia
| Palanca | Impacto típico |
|---|---|
| Automation (RPA) | 30-60% ahorro tiempo en tareas repetitivas |
| Process redesign | 20-40% ciclo + calidad |
| Centralización SSC | 15-30% costo |
| Self-service | 10-25% tickets soporte |
| IA en decisiones | variable, ROI 12-24 meses |
| Outsourcing | 20-40% costo (con tradeoffs) |

## 4. Stack tecnológico
- **RPA:** UiPath, Automation Anywhere, Power Automate
- **iPaaS:** Mulesoft, Boomi, Workato
- **BPM:** Camunda, Bizagi, Appian
- **Process Mining:** Celonis, UiPath Process Mining, Microsoft Process Mining
- **Low-code:** Power Platform, OutSystems

## 5. Métricas
- FTE-hours liberadas
- Cost-to-serve
- Cycle time
- First-pass yield
- Cost per transaction
- ROI por iniciativa

## 6. Anti-patrones
- Automatizar procesos rotos (paving cowpaths)
- Big-bang sin pilots
- Falta ownership del proceso (process owner)
- Métricas que no se miden post-implementación
