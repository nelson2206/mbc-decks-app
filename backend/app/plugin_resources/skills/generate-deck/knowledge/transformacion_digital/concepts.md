# Transformación Digital · Conceptos Clave

## 1. Componentes core de una TD
1. **Estrategia digital** — visión, ambición, OKRs
2. **Cultura y talento** — change management, upskilling
3. **Procesos** — rediseño, automatización, lean
4. **Tecnología** — modernización, cloud, integración
5. **Datos** — calidad, governance, analytics
6. **Experiencia** — cliente y empleado (CX/EX)

## 2. Frameworks
- **MIT CISR Digital Maturity** — 4 cuadrantes (Customer · Operations)
- **McKinsey Digital Quotient**
- **Gartner Composable Enterprise**
- **TOGAF** para arquitectura empresarial

## 3. Niveles de madurez digital
1. Inicial — esfuerzos puntuales aislados
2. Definido — roadmap pero ejecución parcial
3. Replicable — capacidades estandarizadas
4. Optimizado — métricas, ROI medido
5. Pionero — innovación continua, IA embebida

## 4. Palancas digitales típicas
| Palanca | Tools |
|---|---|
| Cloud migration | AWS, Azure, GCP |
| ERP modernization | SAP S/4HANA, Oracle Cloud |
| CRM y experiencia | Salesforce, HubSpot, Microsoft Dynamics |
| Process automation | UiPath, Power Automate, Camunda |
| Low-code | Power Platform, OutSystems, Mendix |
| Customer experience | Adobe Experience Cloud, SAP CX |
| Workplace digital | Microsoft 365 + Copilot, Google Workspace |

## 5. Métricas de TD
- Revenue digital (% ventas vía canales digitales)
- NPS / CSAT digital
- Adopción interna (% empleados usando tools nuevos)
- Productividad (FTE-hours liberadas)
- Time-to-market (días desde idea a producción)
- ROI por iniciativa

## 6. Anti-patrones (a flagear)
- "Digital Twins" sin propósito claro
- "Migrar a la nube" sin replantear arquitectura (lift-and-shift puro)
- Procesos automatizados de trabajos manuales sin rediseño
- Tecnología antes que cultura
- Programas sin product owner del lado cliente

- Casos peruanos en construcción (Cosapi), banca (BEI), industria
