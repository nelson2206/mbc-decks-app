# Data Analytics · Conceptos Clave que el Agente debe Dominar

## 1. Niveles de analítica
1. **Descriptiva** — qué pasó (dashboards, reportes)
2. **Diagnóstica** — por qué pasó (drilldown, correlaciones)
3. **Predictiva** — qué pasará (ML clásico, forecasting)
4. **Prescriptiva** — qué hacer (optimización, recomendadores)
5. **Cognitiva/Generativa** — RAG, agentes sobre datos

## 2. Pirámide de madurez del dato (Gartner)
- Nivel 1 · Sin estructura, silos
- Nivel 2 · Reportes manuales en Excel
- Nivel 3 · Plataforma centralizada + casos productivos
- Nivel 4 · Self-service + governance maduro
- Nivel 5 · Data-driven cultural · IA embebida

## 3. Frameworks de gobernanza
- **DAMA-DMBOK** · 11 áreas de data management
- **DCAM** (EDM Council)
- **CDMC** (Cloud Data Management Capabilities)

## 5. Procesos core
Data Strategy · Governance · Architecture · Quality · MDM · Metadata · Analytics/BI · ML/IA

## 6. Métricas estándar
- Time-to-insight (días)
- Data quality score (% completitud, validez, consistencia)
- Adopción self-service (% usuarios)
- Costo por TB / query
- % datos catalogados con lineage
- MTTR de incidencias de calidad
